\# ⚙️ Robloader - YouTube vers H265



Robloader est un outil qui permet de télécharger des vidéos YouTube (entières ou extraits spécifiques via timecodes) et de les convertir instantanément en \*\*HEVC (h265)\*\* optimisé pour un import fluide dans \*\*Adobe Premiere Pro\*\*.



\## 🚀 Fonctionnalités

\* \*\*Téléchargement ultra-rapide :\*\* Utilisation de l'API native `yt-dlp` sans restriction de vitesse.

\* \*\*Découpe au Timecode :\*\* Télécharge uniquement la portion demandée.

\* \*\*Optimisation Premiere Pro :\*\* Conversion GPU (NVIDIA NVENC) ou CPU (Secours libx265) en conteneur MP4 parfaitement compatible avec Adobe Premiere.

\* \*\*Interface Graphique :\*\* Design sombre et épuré conçu avec `CustomTkinter`.
